# OSHIGLASS — 推し砂時計

好きな色・形・文字を「砂」にして、ひっくり返して眺めるブラウザ砂時計です。

1種類の砂だけで遊ぶほか、2種類の砂を別々に設定して、配合比率や初期配置（混合／左右／上下／3層）を選べます。

## 主な機能

- 砂の色をプリセットまたはHEXで指定
- 粒の形を「丸」「星」「文字」から選択
- 文字は最大10文字まで。各文字が別の粒として落下
- 1種類 / 2種類モード
- 2種類モードでは砂A・砂Bに色・形・文字を個別設定
- A:Bの配合比率を指定
- 初期配置を「混合」「左右」「上下」「3層」から選択
- 粒サイズ、時間の調整
- 反転アニメーションと粒子物理
- 音のON/OFF
- 音の質感を「さらさら」「ガラス粒」から選択
- ダーク / ライト表示切替
- PC / スマートフォン対応

## 使い方

GitHub Pagesで公開する場合は、このリポジトリのルートをPagesの公開元に指定してください。

ローカルでも `index.html` をブラウザで開くだけで動作します。

## プライバシー / 通信

この v1.0.0 には外部APIや外部音源を使用する機能はありません。砂の描画・物理演算・効果音生成はブラウザ内で行います。

テーマ・音設定など一部の設定はブラウザの `localStorage` に保存されます。

※ アクセス解析はこのビルドにはまだ組み込んでいません。

## ファイル

- `favicon.svg` — favicon
- `robots.txt` — 公開サイト向けクロール許可
